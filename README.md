# CCM 圣水记牌器

皇室战争（国服）实时圣水 + 敌方手牌追踪悬浮窗。

## 功能

- **圣水球**：屏幕中右侧实时显示敌方圣水点数
- **敌方手牌**：左上角显示敌方已出的牌，未知的显示为灰色占位
  - 已知手牌正常显示，下一张略小
  - 觉醒卡在第 2 次出牌时换用觉醒贴图
  - 精英卡整场保持精英外观
- **落点预判**：敌方下牌瞬间，在战场位置显示卡片 + 准星，0.8 秒后淡出

## 原理

直接读游戏进程内存（`process_vm_readv`，需 root），不用截图/图像识别。

- 实体扫描：从 HP 组件特征定位塔和单位对象
- 敌我判定：实体 `+0x78` 字段，`1` = 我方，`0` = 敌方
- 圣水：多轮采样筛出「每 2.8s +1」的 int32
